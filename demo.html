Welcome to My DevOps Project

This project demonstrates the implementation of a Jenkins CI/CD pipeline to automate the build, testing and deployment of a static website. The application is containerized using Docker and served through the Nginx web server.

Technologies Used

Jenkins

Automates the CI/CD pipeline through Checkout, Build, Test and Deploy stages.

Docker

Builds Docker images and runs the application inside containers.

Nginx

Serves the static HTML website through an Nginx web server.

Git & GitHub

Manages source code and stores project files in a GitHub repository.

HTML & CSS

Creates and designs the responsive frontend website.

Jenkins CI/CD Workflow

  1. Checkout - Retrieve source code from GitHub.
  2. Build - Build Docker image using Dockerfile.
  3. Test - Verify the Docker image and application.
  4. Deploy - Run the application inside a Docker container.

About This Project

The objective of this project is to understand DevOps practices and automate the software deployment process using Jenkins and Docker. Jenkins executes the pipeline stages, Docker provides application containerization, and Nginx serves the frontend website.
